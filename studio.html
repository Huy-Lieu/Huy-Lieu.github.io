Write & Publish

No Markdown files, no git — write here, publish straight to the site. Notes land in the logbook, posts become reader pages, images go to the library.

setup · github token

The Studio publishes by talking to GitHub for you. It needs a token once — stored only in this browser, never sent anywhere except api.github.com.

  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access → Only select repositories → Huy-Lieu.github.io
  3. Permissions → Repository → Contents: Read and write (the only permission needed)
  4. Generate, copy, paste below — done forever. Also revoke the old token while you're there.
